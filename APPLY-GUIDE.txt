저주·부적 시스템 변경 파일 적용 안내

기준 저장소: wanttogames/survivor-protocol
기준 커밋: 23120dcbbe9f237ccd482b882eecb16768dee880
Windows 원본 폴더를 직접 수정한 것이 아니라 연결된 저장소의 사본에서 구현·검증했습니다.
멈춘 Work의 미커밋 변경사항은 이 묶음에 포함되어 있지 않을 수 있습니다.

1. ZIP을 프로젝트 바깥의 새 폴더에 압축 해제합니다.
2. PowerShell에서 압축 해제 폴더로 이동합니다.
3. 다음 명령을 실행합니다.
   powershell -ExecutionPolicy Bypass -File .\APPLY.ps1 -ProjectPath "C:\work\survivor-protocol"
4. 적용 후 프로젝트에서 다음을 실행합니다.
   npm run build
   npm test
   npm run dev

APPLY.ps1은 모든 대상 파일의 SHA256을 먼저 검사합니다.
로컬 파일이 기준 버전 또는 이미 적용된 버전과 다르면 복사를 시작하지 않고 중단합니다.
이 경우 payload를 무조건 덮어쓰지 말고 충돌한 파일을 비교·병합해야 합니다.
정상 적용 시 기존 파일은 프로젝트의 talisman-backups 아래에 백업합니다.

수동 병합할 때 변경 파일 목록은 FILES.txt, 기준 해시는 manifest.json을 확인합니다.
node_modules, 기존 음원, 기존 에셋은 포함하지 않았습니다. 의존성 추가는 없습니다.

개발 모드 즉시 확인 (브라우저 개발자도구 Console):
window.__SURVIVOR_GAME__.scene.getScene('Game').triggerTalismanEvent('samdo')
사용 가능한 id: samdo, gate, hunger, trick, reaper, moon
일시정지와 기존 카드 UI를 닫은 상태에서 호출합니다.
프로덕션 빌드에는 디버그 버튼과 window.__SURVIVOR_GAME__ 노출이 없습니다.
